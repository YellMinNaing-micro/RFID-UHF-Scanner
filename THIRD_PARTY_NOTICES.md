# Third-party notices

## RFID hardware SDK

The Kotlin bridge references classes supplied by an RFID hardware-vendor SDK, including packages such as:

- `com.android.hdhe.uhf.reader`
- `com.android.hdhe.uhf.readerInterface`
- `cn.pda.serialport`

The corresponding JAR and native `.so` binaries are proprietary vendor components. No license granting public redistribution was found with the supplied SDK packages, so those binaries are intentionally excluded from this repository and from the MIT license grant.

Users must obtain the appropriate SDK, license, and redistribution permission directly from their hardware vendor.
